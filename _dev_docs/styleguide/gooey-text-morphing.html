Gooey Text Morphing Animation

Gooey Text Morphing 효과란?

SVG 필터와 블러 효과를 활용하여 텍스트가 유기적으로 변형되는 애니메이션입니다. 두 개의 텍스트 레이어가 블러와 투명도를 조절하며 부드럽게 전환됩니다.

주요 특징

  • SVG feColorMatrix Filter - 텍스트 가장자리를 선명하게 처리
  • Dynamic Blur - 거리 기반 블러 효과 (0-100px)
  • Opacity Morphing - 부드러운 투명도 전환
  • RequestAnimationFrame - 60fps 부드러운 애니메이션
  • Customizable Timing - morphTime과 cooldownTime 조절 가능

현재 설정

  • 텍스트 배열: ["Practice", "makes", "Perfect!"]
  • Morph Time: 1초
  • Cooldown Time: 0.25초
