# 범례

## 테이블 형식
- `^` : 이전 셀과 병합 (동일 교재 사용)
- `(N-M)` : Lv.N부터 Lv.M까지 적용
- `-` : 해당 레벨 미제공

## 리스트 형식
- `Lv.N`: 단일 레벨 적용
- `Lv.N-M`: N부터 M 레벨까지 동일 교재 적용

---

# 활용 가이드

## 레벨 테스트 후 교재 선정
1. 학습자 레벨 확인
2. 해당 언어의 과정 선택 (일반회화/비즈니스/주제토론/시험대비)
3. 코스 내에서 레벨에 맞는 교재 확인

## 교재 진도 계획
1. 현재 레벨의 교재 완료
2. 다음 레벨 교재로 이동
3. 병합된 레벨(예: Lv.4-6)의 경우 해당 기간 동안 동일 교재 사용

## 코스 변경 시
- 동일 레벨 내에서 다른 코스로 변경 가능
- 예: 영어 Lv.3에서 Smart Choice 2 -> Stretch 1-2로 변경
