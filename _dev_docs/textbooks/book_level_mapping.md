# 교재-레벨 매핑 가이드

## 1. 개요

### 1.1 목적
이 문서는 `app/static/images/books/` 디렉토리에 실제 이미지가 있는 교재만을 대상으로 코스 레벨과의 매핑을 정의합니다. Learning Level 테이블 및 Textbooks Gallery 섹션 구성에 사용됩니다.

### 1.2 적용 범위
- 영어 교재: 31개 (일반회화 20개 + 시험대비 11개)
- 일본어 교재: 19개 (일반회화 12개 + 비즈니스 4개 + 시험대비 3개)
- 중국어 교재: 1개 (시험대비)
- **총 51개 교재** (이미지 보유 기준)

### 1.3 레벨 체계
- 9레벨 시스템: Lv.1 ~ Lv.9
- 레벨 그룹:
  - Beginner: Lv.1-3
  - Pre-intermediate: Lv.4-5
  - Intermediate: Lv.6-7
  - Advanced: Lv.8-9

## 5. 이미지 파일 경로 규칙

### 5.1 기본 경로
```
app/static/images/books/
```

### 5.2 파일 명명 규칙
| 파일 유형 | 명명 패턴 | 예시 |
|----------|----------|------|
| 커버 이미지 | `{bookId}_cover.png` | `stretch1_cover.png` |
| 샘플 이미지 1 | `{bookId}_01.png` | `stretch1_01.png` |
| 샘플 이미지 2 | `{bookId}_02.png` | `stretch1_02.png` |
| 샘플 이미지 N | `{bookId}_0N.png` | `stretch1_03.png` |

### 5.3 ID 명명 규칙
- **내부 ID**: camelCase (예: `stretchStarter`, `americanEnglishFile4`)
- **갤러리 ID**: kebab-case (예: `stretch-starter`, `american-english-file-4`)
- **변환 규칙**: camelCase → kebab-case (갤러리 data-book 속성용)

### 5.4 이미지 크기 권장
| 용도 | 권장 크기 | 비율 |
|------|----------|------|
| 커버 썸네일 | 200x280px | 5:7 |
| 모달 커버 | 300x420px | 5:7 |
| 샘플 페이지 | 600x800px | 3:4 |

## 6. 갤러리 모달 데이터 스키마

### 6.1 textbookData.js 데이터 구조

```javascript
textbooks: {
  bookId: {
    id: string,           // camelCase ID
    galleryId: string,    // kebab-case ID (갤러리용)
    name: string,         // 교재명
    publisher: string,    // 출판사
    levels: string[],     // 적용 레벨 배열 ['4', '5', '6']
    levelRange: string,   // 레벨 범위 문자열 'Lv.4-6'
    category: string,     // 카테고리 (general/business/discussion/test-prep)
    coverImage: string,   // 커버 이미지 경로
    description: string,  // 교재 설명
    objectives: string[], // 학습 목표 배열
    features: string[],   // 특징 배열
    samples: string[]     // 샘플 이미지 경로 배열
  }
}
```

### 6.2 tableRows 구조 (레벨 테이블용)

```javascript
tableRows: [
```

## 7. 레벨 테이블 구성 가이드

### 7.1 테이블 셀 매핑

각 레벨 테이블의 셀은 해당 레벨에서 사용 가능한 교재를 나타냅니다.

#### 영어 일반회화 예시
```html
<table class="curriculum-table">
  <thead>
    <tr>
      <th>레벨</th>
      <th>Stretch</th>
      <th>Smart Choice</th>
      <th>New Connection</th>
    </tr>
  </thead>
  <tbody>
    <tr data-level="1">
      <td>Lv.1</td>
      <td data-book="stretch-starter">Starter</td>
      <td>-</td>
      <td data-book="new-connection-1">1</td>
    </tr>
    <!-- ... -->
  </tbody>
</table>
```

### 7.2 교재 클릭 이벤트

```javascript
// data-book 속성으로 교재 식별
cell.addEventListener('click', () => {
  const galleryId = cell.dataset.book;
  const bookId = galleryIdMapping[galleryId];
  openTextbookModal(bookId);
});
```
