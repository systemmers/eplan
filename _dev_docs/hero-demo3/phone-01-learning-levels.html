9단계 학습 레벨

체계적인 9단계 커리큘럼으로 초급부터 고급까지 단계별 학습

L1

Beginner

입문 단계

기초 인사말과 자기소개, 간단한 일상 표현을 학습합니다.

목표: 기본 의사소통
L2

Elementary

기초 단계

일상생활에 필요한 기본 문장 구조와 어휘를 학습합니다.

목표: 기본 문장 구사
L3

Pre-Intermediate

초중급 단계

다양한 상황에서 의견을 표현하고 간단한 대화를 이어갑니다.

목표: 상황별 대화
L4

Intermediate

중급 단계

복잡한 주제에 대해 논리적으로 의견을 전달할 수 있습니다.

목표: 논리적 표현
L5

Upper-Intermediate

중상급 단계

비즈니스 상황에서 전문적인 커뮤니케이션이 가능합니다.

목표: 비즈니스 커뮤니케이션
L6

Pre-Advanced

준고급 단계

프레젠테이션, 협상 등 고급 비즈니스 스킬을 습득합니다.

목표: 프레젠테이션/협상
L7

Advanced

고급 단계

원어민 수준의 유창한 대화와 토론이 가능합니다.

목표: 원어민급 토론
L8

Expert

전문가 단계

전문 분야에서 깊이 있는 토론과 발표가 가능합니다.

목표: 전문 분야 토론
MASTER
L9

Master

마스터 단계

최고 수준의 영어 실력으로 어떤 상황에서도 완벽한 소통이 가능합니다.

목표: 완벽한 글로벌 커뮤니케이션
